# Optional integrations (planned)

No optional Minecraft mod is required by the v0.1 scaffold.

- `tacz/`: proposed integration with Timeless and Classics Zero. **Not implemented.**
- `recruits/`: compatibility investigation only. **Not implemented.**

Do not add mandatory mod dependencies to the core module just to support a specific weapon or NPC mod. Test TaCZ and Recruits combinations in a separate CurseForge profile before considering an integration stable.
