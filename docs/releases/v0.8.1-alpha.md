# NPCortex v0.8.1-alpha — Agentic AI Brain

Public alpha milestone based on [SIRP00M/NPCortex](https://github.com/SIRP00M/NPCortex) v0.8.0 main. The agentic prototype engineering work previously labeled v0.8.4–v0.8.5.5 is consolidated into this published version number. Build metadata uses `0.8.1-alpha` (Python package uses `0.8.1a0`).

## Scope

- Minecraft 1.20.1 / Forge 47.4.10 / Java 17; Python 3.10+ / Ollama / Qwen 3 8B.
- AI decides validated next skills based on server observations and feedback: observe → reason/select → validate/execute → verify → replan.
- The agentic task pilot handles `minecraft:oak_log` 1–16 units (legacy flows retained for other tasks).
- Per-NPC ledger, cancel/resume, owner checks, finite LLM/timeout/no-progress budgets, and server-verified inventory counts.
- Mining, reach, pathfinding, leaf and temporary-scaffold primitives remain Java-authoritative and bounded.

## Manual test evidence and known issues

In an actual Forge client, Yui completed a 1-oak-log request with `mined=1`, `stored=1/1`, and server confirmation that the log remained in the NPC bag. Nearby leaves / terrain prevented safe standing positions in other cases. After manual removal of obstructing foliage, the nearby single-log task succeeded. These observations **do not** establish robust tree-scale navigation or reliable autonomous obstacle removal.

Player-like automatic item magnet pickup is **not yet implemented**. The current pilot may select `pickup` using Qwen after determining a drop is reachable. Some failures still halt/ pause rather than recover.
