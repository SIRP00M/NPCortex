# NPCortex v0.8.2-alpha — Build Hotfix 1

## Reported problem

`build-agentic-v085.ps1 -SkipTests` failed in `AgenticTaskController.java:264` with
`illegal start of type` and 137 cascading Java compiler errors.

## Root cause and fix

An extra `}` after the `mine` branch closed the `if/else if` chain one level too early.
The hotfix removes exactly that brace; no skill, permission, task, inventory, or
world-edit behavior has been intentionally changed.

The standalone test runner now invokes `scripts/check-java-syntax-v082.ps1`, which
uses the JDK compiler parser (`--release 17`) on all Forge Java sources. This check
catches brace/syntax errors without downloading Forge, but **does not type-check
Forge APIs or prove the Minecraft mod builds/runs**.

## Validation in patch development environment

- Python Backend tests: 156 pass.
- Pure Java policy tests: 38 assertions pass (24 agent + 14 whole-tree).
- Forge Java 17 source syntax parse: 54 files, 0 errors.
- Full Forge Gradle build: **not run** (Forge/Gradle toolchain unavailable here).
- Ollama live inference / Minecraft in-game: **not run**.

## On your Windows project

1. Close the running Minecraft dev client and backend.
2. Run the included `scripts/install-buildfix-v082.ps1` against this BuildFix Update ZIP.
3. Run `./scripts/test-v082.ps1` and `./scripts/build-agentic-v085.ps1 -SkipTests`.
4. Only after Gradle succeeds, run `./scripts/dev-forge.ps1 -Task runClient`.

All existing saves, SQLite memory, character packs, and private config remain untouched.
