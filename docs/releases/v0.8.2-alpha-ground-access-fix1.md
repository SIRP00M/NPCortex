# NPCortex v0.8.2-alpha — 3D Ground Access Fix 1 (experimental)

## The observed failure

An already-committed high/branching tree returned `approach(b10)` even though `BrainSkills.approach` could not find any safe ground standing position with line of sight and reach. The NPC paused while the server still tracked 15 remaining logs.

## Scope of this patch

- `BrainSkills.safeVisibleStands` becomes the single source of the bounded geometry rules shared by the approach executor and the observation probe. The probe exits at its first viable stand to reduce server load. It only checks geometry; it cannot guarantee a reachable navigation path.
- `BrainObservation` adds a boolean `ground_stand_possible` to each observed log. It does NOT authorize digging, moving, or placing blocks.
- `backend/brain.py` validates the new field and prevents Qwen from choosing `approach` for a target without any viable ground standing point. Qwen is free to select any OTHER grounded skill, including `climb` if already committed, equipped, and within scaffold limits.
- Task status now exposes `groundStands`, the count of current observed log targets having candidate safe ground standing spots. It does not indicate successful Pathfinder routes.
- Adds/updates tests for grounded affordance filtering and invalid observations. Existing owner/permission/world safeguards, whole-tree commitments, pickup, character packs and memory stay unchanged.

## Limits

This is NOT a general-purpose 3D movement system. Java scaffold is still a single root-side pillar with max 6 levels; it does not yet create bridges/platforms for remote branches, and vanilla 2D pathfinding may still reject geometry-viable destinations. In-game results on giant spruce, jungle, acacia, mangrove, etc. remain unverified. Qwen HTTP 200 and Python unit tests do not prove task success.

## Install

Apply this patch only on top of `NPCortex_v0.8.2-alpha_VanillaTreesFoundation1_BuildFix1`. Stop client/backend, unpack UpdateOnly, and run `scripts/install-ground-access-v082.ps1 -ProjectRoot F:\AI\NPCortex`. Installer checks old/new SHA256 and makes a backup of every overwritten file. Abort if source has local edits; never overwrite arbitrary changes.

Then run `scripts/test-v082.ps1`, `scripts/build-agentic-v085.ps1 -SkipTests`, and launch separate backend + Forge dev client.

## In-game acceptance

1. Save/back up a test world. Spawn Yui near a *small* naturally generated tree. Collect at least one log with `task gather` to confirm baseline.
2. Test a tree with high hanging branches on terrain similar to the original screenshot. Capture `task status` and Backend Console. Look at `groundStands`, `chosen`, `scaffoldMaterial`, `stalls`, `treeRemaining`, `scaffold`.
3. **Expected improvement:** `approach(bN)` should no longer be offered for a log where ground standing points are geometrically impossible. Qwen may select `climb`, another log, or report unsafe failure. This is not a guarantee of a successful climb or whole-tree completion.
4. If a scaffold is built, confirm task cleanup has `scaffold=0` at completion. Never count tree complete while `treeRemaining > 0`.
