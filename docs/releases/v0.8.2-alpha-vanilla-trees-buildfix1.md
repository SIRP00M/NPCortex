# NPCortex v0.8.2-alpha — Vanilla Trees Foundation 1 Build Fix 1

## Issue

Forge Java 17 compilation failed on `WholeTreeTracker.java:128`:

`incompatible types: cannot infer type-variable(s) T` on the generic `Comparator.comparingInt(BlockPos::getY)` chain.

## Change

`verifiedRoot()` now uses explicitly typed `Comparator.<BlockPos>comparingInt(...)` with `BlockPos` lambda arguments and `mapToObj(packed -> BlockPos.of(packed))`. No behavior, tree identification, AI tool policy, or world-edit safeguards are intentionally changed.

## Installation

Unpack the Update Only ZIP to a temporary folder and run `scripts/install-vanilla-trees-buildfix1-v082.ps1 -ProjectRoot F:\AI\NPCortex` from that extracted folder. The installer checks the previous Source SHA-256 and makes a backup before replacing the Java file. For users with local edits, manually review the small change instead of overwriting.

## Tests

Run `scripts/test-v082.ps1` (standalone tests) and then `scripts/build-agentic-v085.ps1 -SkipTests` (actual Forge build). Minecraft in-game tests are separate. This fix's offline Java 17 comparison-expression compilation check is not a full Forge build.
