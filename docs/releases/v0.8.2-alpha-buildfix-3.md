# NPCortex v0.8.2-alpha Build Fix 3

Fixes the PowerShell build wrapper falsely throwing `Tests failed; aborting Forge build.` with `-SkipTests` after a prior failed Gradle/native command left `$LASTEXITCODE=1`.

Change: the test result check now runs only if tests were actually invoked. This does not bypass Forge compilation. **No Java, backend, world, character, or task logic changed.**

## Install

Extract Update Only ZIP to a temporary folder. Run `scripts/install-buildfix3-v082.ps1 -ProjectRoot "F:\AI\NPCortex"` from the extracted folder. Existing build script is backed up automatically and hash validated; local modifications are not overwritten.

## Test

`cd F:\AI\NPCortex`
`./scripts/build-agentic-v085.ps1 -SkipTests`

Alternatively, `./scripts/dev-forge.ps1 -Task build` directly bypasses the wrapper without changing the source.

## Validation scope

Archive integrity and static script verification performed. PowerShell execution on Windows, Forge Gradle build and Minecraft in-game testing must be performed on the user's machine.
