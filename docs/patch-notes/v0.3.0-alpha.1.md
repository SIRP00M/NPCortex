# NPCortex v0.3.0-alpha.1 — Player-like Survival & World Actions

**Development alpha for Minecraft 1.20.1 / Forge 47.4.10.** This is not a stable release, full player-parity certification or autonomous AI worker.

## What changed

- NPCs now run more Vanilla survival behavior, including fire/lava, drowning, hunger/regeneration, item consumption and pickup, without running movement physics twice.
- NPCs can participate in the server player registry and vanilla player selectors; section-aware chunk tracking helps maintain player-style world simulation beyond the initial spawn point.
- Stats and advancements have explicit persistence handling so simulated players can keep Vanilla records through supported lifecycle paths.
- Server-validated operator actions for combat, selected item use, sleeping and limited container handling.
- Experimental guarded place-block and use-block workflows with persistent receipts, ownership fencing and restricted interaction targets.
- Added parity and PAP GameTest suites, datapack source and public testing scripts.

## What remains experimental

- PlayerList registration changes server player counts and may affect third-party mods; portal travel and parts of death/respawn still differ from real players.
- The TAB player list may show an internal GameProfile name. AI-driven dispatch for the new operator actions is not available.
- PAP can validate limited place/use actions, but autonomous approach-to-target is blocked on the existing C2 decision contract. No unrestricted crafting, container automation or fully autonomous resource gathering is claimed.
- Performance measurements are not production acceptance, especially for 5/10 NPCs whose chunk rings do not overlap. Full Owner multiplayer, restart, gameplay and server testing remain open.

## Compatibility and testing

- Forge `0.3.0-alpha.1`, Python backend package `0.3.0a1`; Minecraft 1.20.1, Forge 47.4.10, JDK 17.
- Linux backend and Windows PowerShell CI workflows remain separate; the Windows safety tests are not removed or silently passed.
- Follow the [parity gameplay guide](../parity/PARITY_OWNER_GUIDE.md) and [PAP Windows acceptance guide](../pap/PAP_ACCEPTANCE_WINDOWS.md) in disposable test worlds.
