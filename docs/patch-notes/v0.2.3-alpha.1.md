# NPCortex v0.2.3-alpha.1 — Patch Notes

**Milestone:** Safer NPC task planning, read-only task management, and movement previews  
**Date:** 2026-10-23 · **Branch:** [`main`](https://github.com/SIRP00M/NPCortex) · **Status:** Development candidate (not a stable release)

This file **updates the earlier `v0.2.3-alpha.1` E-P0 patch notes in-place**. There is no new version number; it is an expanded source candidate of the same milestone.

## What's new

- **Persistent job records:** C-F1 diagnostic journaling and C-F3 durable task graph can keep track of task requests and the evidence behind them. A logged or acknowledged action is **not** automatically a completed in-game action.
- **Safe view of the nearby world:** C-F2 reads loaded blocks, nearby entities/items and cautious permission results from the Forge server. Unloaded/unknown areas are never guessed as safe or editable.
- **Read-only task queue:** E-P0 preview, E1 FIFO task submissions and E2 operator-driven dispatch/verification allow testing task ordering, resource reservations and fresh evidence without NPCs mining, placing blocks or moving automatically.
- **Preview a possible movement target (E3-D G1):** An operator can run `/npcortex debug cplus taskmovepreview yui <x> <y> <z>` with integer target coordinates. The system verifies that the NPC is alive and grounded, not currently controlled by Follow/C2, has no uncertain C2 action, and that the destination is local and loaded. Python validates the typed intent and stores a durable, deduplicated preview in SQLite. **No movement starts, no FIFO task is added and no world effect occurs.**
- **Additional developer tests and checklists:** New E1/E2/E3 targeted Python tests, scripts and Windows gameplay checklists.

## Try the E3-D G1 preview (operator-only)

With the local authenticated backend available, launch a disposable Creative test world, check NPC state, then enter nearby **integer** coordinates:

```text
/npcortex debug cplus world yui
/npcortex debug cplus taskmovepreview yui <x> <y> <z>
/npcortex debug cplus taskqueue yui
```

Replace the angle-bracket placeholders with numbers. Expected: `PREVIEW_ONLY`, no movement and no task queued. A target outside the local bounds, unloaded target or busy/ungrounded actor must be rejected conservatively. This is a **test procedure**, not a confirmed Windows acceptance result for this ZIP.

## Still not available

E3-D G2 live guarded navigation, G3 movement completion/cancellation/recovery, E3-E automatic multi-node movement DAG, block break/place/use/pickup, mining/building, automated Qwen dispatch and claim-protection integration remain outside this increment. Read-only observations and movement previews cannot grant world-modification permission.

- **Package validation:** focused Python regression **90/90 PASS** (Exit Code 0); Java isolated C-F2 authorization policy **16 checks PASS** under JDK 21 targeting Java 17; ZIP integrity/version consistency and 44 internal document links passed. These are not Forge gameplay tests.
