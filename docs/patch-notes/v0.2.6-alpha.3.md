# NPCortex v0.2.6-alpha.3 — Patch Notes

**Alpha maintenance update · 28 October 2026**  
**Compared with:** GitHub `main` `v0.2.6-alpha.2` (`cbd9cd9`).

## NPC movement tasks now finish more reliably

Previously, a guarded movement task could reach the destination but fail its final completion check because the verifier treated target block coordinates as a corner, while navigation actually stopped near the **center** of the block.

This update aligns the Java and Python completion checks with navigation: target `(x, y, z)` is evaluated at `(x+0.5, y, z+0.5)` without relaxing the original three-dimensional arrival tolerance. It adds shared test examples covering ordinary coordinates, negative coordinates, acceptance boundaries and rejection cases. Task ownership, cancellation and durable recovery guardrails remain unchanged.

## Verification

The project owner confirmed a focused **Windows Minecraft single-player G5 Revision 6 p18** test passed on 28 October 2026, with a completed C2 move, a completed E3/G3 durable terminal and matching database records. That result is specific to the tested scenario and does **not** establish complete G5 acceptance, multiplayer compatibility or performance readiness.

**Still open or limited:** p08 terminal-reason discrimination, p10 cancellation quiescence, p11 save/quit timing proof, TAB list visible-name presentation, multi-round MSPT/profiler acceptance, dedicated servers and general autonomous world interaction. Prior 1/3/5/10 NPC functional results are retained for their earlier test environments.

## Refreshed source package (same version)

- **Inspect nearby terrain without modifying it.** The Stage 4 M04 observe command reports loaded block information and distinguishes partial coverage from a complete observation. It does not grant permission to break, place or pick up anything.
- **More dependable local API responses.** A blocked Host-header POST can return its 403 response reliably when the request body is safely framed and within existing drain limits.
- **Better developer verification.** Java self-tests participate in Gradle `check`/`build`, an offline verification runner is available, and M03 tick timing rejects unmatched end samples.

These features are experimental; the new world inspection command has not been gameplay-accepted in this packaging session. The existing `v0.2.6-alpha.3` version number is unchanged.

## Compatibility

- Minecraft Java 1.20.1, Forge 47.4.10, JDK 17; Python package `0.2.6a3`.
- No database migration or new player commands are introduced. Existing durable/fail-closed rules still apply.
- This is a development source snapshot, not a stable release.
