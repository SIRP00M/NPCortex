# NPCortex v0.2.5-alpha.1 — Patch Notes

**Development alpha · 27 October 2026**  
Previous public version: `v0.2.4-alpha.2`.

## Highlights

### Create NPCs with their own personalities

An in-game **NPCortex Manager** is now available from the ESC/Pause menu. Create a new NPC without first making a matching folder in `character-packs/`, choose a structured personality or a raw prompt, and edit it later. Each actor has a revisioned Character Profile stored in SQLite. Legacy Character Packs remain supported.

### Try longer navigation on loaded terrain

New operator command: `/npcortex c2 navlong <npc> <x> <feetY> <z>`.

The NPC can attempt longer routes as bounded, internal movement legs without loading new chunks. The system limits planning, elapsed time and repeated lack of progress; failures may end conservatively. It is an **experimental navigation mode**, not unrestricted world-scale autonomous pathfinding.

### Safer persistence and testing

The profile system uses additive **SQLite v5**, with immutable revisions and an **opt-in migration** for existing databases; it checks a backup first. New server/client Manager messages are permission-gated, and PowerShell fallback and navigation test harnesses are included.

## Compatibility and known limitations

- **Forge:** `0.2.5-alpha.1` · **Python:** `0.2.5a1`.
- Older SQLite databases require backup/rehearsal and `NPCORTEX_ALLOW_SCHEMA_V5=1` before upgrading. Do not treat the opt-in as safe without checking the resulting backup and migration.
- Owner-confirmed **Windows single-player GUI smoke tests passed for tested scenarios**, including creating and registering a custom profile. Dedicated server, existing-database migration, multiplayer and full G5 long-range gameplay/performance remain unverified.
- The NPC nametag may continue to display its internal Minecraft GameProfile-style name. A profile display name and a game-rendered nametag are not yet guaranteed to be identical.
- NPCortex does **not** currently claim autonomous block mining, item pickup, guaranteed cross-chunk recovery or complete AI-generated personalities.
