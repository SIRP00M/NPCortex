# NPCortex v0.2.6-alpha.1 — Patch Notes

**Development alpha · 27 October 2026**  
Previous public milestone: `v0.2.5-alpha.1`.

## More readable NPC names

NPCs can show their chosen logical names (such as `Reika` or `Mika`) above their heads instead of their internal Minecraft GameProfile names. A server-to-client name map refreshes after login, rejoin and dimension changes without altering the saved NPC identity or command selectors. This experimental release also includes a dedicated TAB display-name formatter; **the new TAB behavior is not yet confirmed in game**.

The project owner reported above-head naming and persistence passing in the tested Windows single-player scenarios. That does not certify dedicated servers, all clients or third-party compatibility.

## Better tools for testing navigation with multiple NPCs

The G5 verification toolkit now includes more isolated test runs, per-NPC lanes for 1, 3, 5 and 10 NPCs, profile/goal/action cross-checks, and safer evidence collection. Additional read-only movement diagnostics make it easier to investigate why a route stopped or a cancellation did not cover the intended state.

In the reported 22-scenario Windows single-player run, **18 passed, 3 remain pending and 1 is unverified**; there were no reported failed verdicts. The 1/3/5/10 functional lanes passed for that setup. Cancellation quiescence, save/quit timing evidence, one terminal review and precise long-no-progress categorization remain unresolved. Performance measurements are *not accepted* as a complete MSPT benchmark.

## Compatibility and limitations

- Minecraft Java 1.20.1, Forge 47.4.10, Java 17; Python backend distribution `0.2.6a1`.
- Old character profiles and internal GameProfile UUID/name identities are preserved. Display naming is not identity migration.
- G5 tests and read-only diagnostics do not expand NPC pathfinding or world-mutation capabilities.
- Full Forge client build, Minecraft testing on this exact GitHub-ready ZIP, dedicated-server compatibility, TAB naming and multi-round performance acceptance have not been verified in this packaging session.
- NPCortex still does not claim certified autonomous mining, item pickup or unrestricted unloaded-chunk navigation.
