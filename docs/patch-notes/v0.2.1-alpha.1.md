# NPCortex v0.2.1-alpha.1 — Development Patch Notes

**Date:** 2026-10-22  
**Channel:** `Development` milestone candidate (not a stable release or GitHub tag)  
**Previous development milestone:** [`v0.2.0-alpha.2`](v0.2.0-alpha.2.md) — Navigation & Persistent Follow  
**New source baseline:** Airborne Follow Target Projection Fix Full Repository Candidate

## Highlights

This new Follow Stability milestone focuses on **how a ground-bound Player-based NPC follows a player who is flying**. The NPC should not steer toward an unattainable airborne Y coordinate as if it were a walkable destination. The update also includes follow-trajectory stabilization, terrain-native detour improvements, and bounded persistent 3D follow sessions developed since the previous packaged Alpha.

### New and improved

- **Airborne Follow Target Projection:** detect real Creative/elytra flight with brief debouncing (2 ticks enter, 4 exit), keeping normal jumping on the grounded navigation logic. Use the player's horizontal XZ separation for stop/resume gating while they are flying.
- **Verified ground-height reference:** project an airborne target to accessible ground supports selected from already checked, bounded and loaded 3D graph nodes. If no nearby reachable support is found, select a neutral scoring Y; do not invent blocks, skip hazards or force-load chunks.
- **Consistent route selection:** use projected target height in normal Follow planning, active session extension and prepared continuation. Flight/ground mode changes discard stale speculative hints, but do not steal ownership of an active C1 motion token.
- **Debugging:** `/npcortex c2 followstatus yui` now exposes `targetMode`, `targetProjection` and `projectedY`.
- **Stable Trajectory Follow B:** add lateral damping, waypoint crossing and careful stopping to reduce left-right wobble on verified corridors.
- **Persistent Terrain-Native Follow and Smooth Hardening C:** safer bounded terrain detours, continuity preferences, predictive continuation hints and waiting/handoff diagnostics.
- **Persistent mixed 3D Follow:** bounded movement stages including WALK, STEP_UP, STEP_DOWN, JUMP_UP and SAFE_DESCEND, preserving C1 motion ownership and verifying each transition before progression.

## Safety and scope

- C1 `Custom ServerPlayer` remains the exclusive physical movement, collision and combat owner; the change does **not** allow the NPC to fly, teleport, force-load terrain or ignore unsafe edges.
- The local terrain projection is a planning reference, **not proof of a route**; physically verified motion receipts are still required.
- Most fine-grained Windows Quality Gate cases are still open. Use [`PENDING_TESTS.txt`](../../PENDING_TESTS.txt) and the [Airborne Windows checklist](../c2-airborne-target-projection-windows-checklist.md).
- Retain `v0.2.0-alpha.2` Patch Notes for historical context. `CHANGELOG.md` remains the **single consolidated chronological changelog**; this file is a user-facing release summary.
