# NPCortex v0.2.6-alpha.2 — Patch Notes

**Development alpha · 28 October 2026**  
Compared with the public GitHub `main` baseline `v0.2.5-alpha.1`. The previously prepared `v0.2.6-alpha.1` archive was not on `main` when this package was assembled.

## Easier-to-read NPC names

NPCs can display their chosen names above their heads while preserving the existing internal Minecraft player identity. Name mapping is refreshed across join, rejoin and dimension transitions. The TAB player-list display formatter is also present, but has **not yet been visually accepted in Minecraft**.

## Stronger navigation testing and debugging

The G5 test toolkit supports separate lanes for 1, 3, 5 and 10 NPCs. Revision 6 improves cancellation timing coverage, read-only long-route failure diagnostics, save/quit checkpoints, guarded movement finalization and correlation of collector evidence. Failed or missing proofs remain pending/unverified instead of being promoted to PASS.

In the earlier Revision 5 Windows single-player run, 18 of 22 scenarios passed, three remained pending and one unverified. Functional 1/3/5/10 NPC lanes passed in that limited setup. **These results do not certify Revision 6** or a multi-run MSPT performance baseline.

## Compatibility

- Minecraft 1.20.1, Forge 47.4.10, Java 17; backend package `0.2.6a2`.
- The new debugging logs do not change the navigation state machine or NPC movement decisions.
- Existing NPC actor/GameProfile identity is unchanged.
- Forge build, dedicated-server and full gameplay verification of this exact package have not been established here.
- No certified autonomous mining, item pickup or unrestricted navigation is included.
