# NPCortex 🧠

**Give Every NPC a Mind of Its Own.**

An open-source, modular AI NPC framework for Minecraft.

NPCortex aims to bring intelligent, customizable NPCs into Minecraft through local and cloud-based language models. Designed for modders, developers, and roleplayers who want to create their own companions, characters, and interactive worlds.

**Planned Features**
- AI-powered conversations and persistent memory
- Fully customizable NPC personalities and character profiles
- Local LLM support via Ollama
- Modular behavior and action systems
- Extensible integrations with other Minecraft mods
- Support for multiple NPCs with independent identities

**Initial Target:** Minecraft 1.20.1 Forge

**First AI Model:** Qwen 3 8B via Ollama

*Status: Early Development*
